003 / Projects

Things I've built

🎯
Current Research

DASCS: Domain-Aware Selective Calibration Sets

Investigating how the composition of the calibration set affects post-training quantization quality for LLMs. The hypothesis: a smaller, domain-aware calibration set (selected with awareness of the deployment distribution) can preserve task accuracy after aggressive weight quantization better than a generic large corpus. Active work, with experiments across INT4 / FP8 regimes.

Quantization INT4 / FP8 LLM Compression Calibration
🔨
Work in Progress

LoraForge

An open-source LoRA fine-tuning and inference optimization toolkit I'm building in the open. The goal is an end-to-end path from dataset to a quantized, served model, targeting ~60% GPU memory reduction via QLoRA plus post-training quantization. Plan is to ship it as a pip-installable package (pip install loraforge) once the API stabilises. Code and progress live on GitHub.
